# Ready, Set, Repair 

A local-first industrial PC diagnostic tool featuring an AI-assisted workbench.

## Features
* **Offline-First:** Java backend (Spark Framework) with local JSON persistence in `AppData`.
* **AI Diagnostics:** Integrates with the Groq API for real-time hardware troubleshooting checklists.
* **Flexible Modes:** Toggle between permanent *Log & Save* entries and off-the-record *Just Ask* queries.

## Quick Start (For Users)

1. Download the latest [release](https://github.com/Juli132/Ready_Repair/releases/) package.
2. Create an extensionless file named `A_oi_t` in the folder and paste your Groq API key inside it using Notepad.
3. Double-click `run.bat` to launch the application.
4. Open `http://localhost:4568` in your browser.
